Sign-in is two steps on a single card: email and password, then a six-digit one-time code. The left panel is the `zr-sage` identity field with `zr-navy` text; the form side is `surface`. On phones the identity panel collapses to a top strip.

Sign-up is by account type. A visitor chooses Request access, picks the account type (Company, Bank, Insurance or Farmer) and gives the fields that type needs (for example organisation, commercial register number and work email; a farmer gives name, mobile number and, if managed, the managing company); Zr3i staff approve it and the invitation arrives by email. Zr3i admin accounts are created only by invitation. Error messages never say which of email or password was wrong.

The language toggle sits at the top end of the page and the DigiWell endorsement stays small at the bottom of the identity panel. Do not add social sign-in.
