Banners state a condition of the data, not a mood. Three are mandatory where they apply: synthetic data (every page in a synthetic namespace, in both languages, with a matching page watermark in reports), accuracy status (shown whenever any figure derives from a measurement and its hit rate is NOT_ESTABLISHED or below the kill line) and withheld by consent (shown with a count, never hidden).

Each banner has an icon, a bold lead phrase and one sentence. They use the status `-bg` tokens with matching text; the synthetic banner uses `synthetic-bg` and `accent-ink`.

Banners are not dismissible. They do not use exclamation marks or the words Warning, Error or Critical.
