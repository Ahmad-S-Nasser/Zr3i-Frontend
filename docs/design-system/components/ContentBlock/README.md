A content block is a `zr-field` green block with `radius-lg` corners with white text and a bold upper-case `zr-amber` heading (Roboto, 0.1em tracking). Blocks sit in a row of two to four on a `zr-sage` or `ground` field, with `space-4` between them and `space-5` padding. No border or shadow.

Use blocks for statements and summaries (login panel, report cover, portfolio headline figures). Do not put tables or forms inside a block. Arabic headings use Cairo with no upper-casing.
