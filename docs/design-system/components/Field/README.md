Every field has a visible label above it, a hint line below it and an error line that starts with a triangle icon and a plain sentence ("Password or email is not recognised"). Colour alone never signals an error.

Inputs are `tap-min` tall with a `line-strong` border (3:1 or better) and a 2px `focus` ring on keyboard focus. Email, ids, numbers, hashes and one-time codes are always `ltr` and left-aligned, inside Arabic pages too; their labels and hints follow the page direction.

The one-time code is six separate boxes in left-to-right order, with autofill and paste support.

Consent checkboxes are never pre-ticked. The label states who receives what and for how long, in the farmer's language.
