Hit rate is plotted per size class with a Wilson interval; the dot is the point estimate and the bar the interval. Draw the kill line at 70% (`flagged`, dotted) and the target at 80% (`confirmed`, dashed), each labelled with its number so the lines are not told apart by colour or dash alone.

Never plot a pooled rate across size classes, and never plot a class with no control set; show "Not established" text in its slot instead.

Charts stay left-to-right in Arabic pages (`ltr` wrapper) while axis words and the caption follow the page language. Use the `data` style for numbers and `ink-muted` for axes.
