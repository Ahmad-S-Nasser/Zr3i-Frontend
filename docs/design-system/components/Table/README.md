Tables list parcels, tranches, users or evidence. Header cells are `label` style on `sunken`; rows are 44px or taller with a `line` divider; the selected row is tinted `zr-mist` (light) or `sunken` (dark) and has `aria-selected="true"`.

Numbers are right-aligned in the page's end direction and set in `data` (mono, Western digits), with the unit in the column header, never in each cell. Parcel ids are left-to-right in both languages.

The state column always uses StatusPill. Missing measurement is "—" with a StatusPill explaining why; an empty cell is never left unexplained.

Rows are never ranked or scored. Sort by id, declared area or state; the default is id.
